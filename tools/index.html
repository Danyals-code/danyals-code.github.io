Why these exist.

Three began inside research projects at UNIST. All are built to be picked up and used by someone else.

  • Made for a study.

    Wheel-accurate robot motion for an MSc thesis, identical product views for form analysis, and a life-size robot in participants’ homes.

  • Open source.

    Source code is on GitHub. True RoboAnimator is GPL-3.0.

  • Used beyond the lab.

    True RoboAnimator has more than 7,000 downloads on Blender Extensions.

  • Reviewed.

    True RoboAnimator passed Blender’s extension review; the Lemmy AR Experience passed Apple’s review for TestFlight on iOS and visionOS.
