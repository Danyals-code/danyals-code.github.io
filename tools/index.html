Blender add-on · Python · GPL-3.0

True RoboAnimator

Converts keyframed chassis animation into physically plausible motion for two-wheeled robots. The add-on detects lateral slip, corrects infeasible paths, computes wheel angles and RPM within speed limits, and exports CSV or JSON for engineering and AR use.

AR/VR UI Designer

A drag-and-drop editor for visionOS-style interfaces. Windows, panels and controls are arranged on a 3D canvas and previewed at eye level with HDRI lighting and realistic glass blur. Volumes with 3D content are supported, with no requirement for Xcode, a Mac or a headset.

iOS · visionOS · Swift

Lemmy AR Experience

A native application that anchors a life-size, animated robot to the floor, allowing its motion to be evaluated in the user’s own environment. Developed for the AR stage of the MSc thesis and distributed to study participants via TestFlight.

Built in Swift with SwiftUI, ARKit and RealityKit. Features include 20 animations categorized as base, functional and expressive; plane detection and placement; pinch-to-pause; and interface-free screen capture. Accessibility settings cover high contrast, text size, haptics and sound.

Swift Web Studio

A browser-based SwiftUI editor that preserves the Swift source. It combines visual editing, a code editor with diagnostics and a live device preview, with export to Xcode, Swift Playgrounds or a Swift package.

Web experiment · JavaScript

Head-tracked perspective

Browser-based fish-tank VR. Webcam face tracking drives an off-axis projection, turning the monitor into a window onto a 3D scene. Builds on work by Ware, Arthur and Booth, and by Deering. All video is processed on-device.

Live demo GitHub
Blender add-on · Python

MultiView Product Renderer

Generates consistent image sets from CAD models (STEP or STL). It centers each model, configures orthographic and perspective cameras with three-point lighting, and batch-renders every view with systematic file naming. Used for AI training data and product form analysis.
